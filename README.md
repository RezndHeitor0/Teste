# Teste-Rondinas
Teste de Armazenamento de Dados de carro


Passo a Passo de como rodar o programa

* Abrir ele no VS Code;

* Antes é preciso instalar o SDK do .NET e também se possível as extensões do C#
   
* Abrir o Terminal para poder executar o código;
  
* Digite ".\Executar.ps1" para a tela de cadastro funcionar;
  
* Use o menu digitando o número da opção:
    1: cadastrar um carro
    2: listar os carros cadastrados
    3: pesquisar por placa, marca ou modelo
    4: atualizar um carro pelo ID
    5: excluir um carro pelo ID
    0: sair
